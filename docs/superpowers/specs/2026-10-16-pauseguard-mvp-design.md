# PauseGuard MVP 实现设计

日期：2026-10-16

## 目标与交付

以 PRD.md 为功能基线，交付 macOS 菜单栏应用：自动循环工作与休息，覆盖多显示器，本地图片合成背景，不影响后台任务，保留紧急解除及故障恢复能力。

完整范围包含计时、设置、首次配置、菜单栏、多屏覆盖、五种背景布局、图集、自定义文案、持久化、生命周期恢复及用户级守护。Windows/Linux 不属于本次实现范围。

用户已确认：关闭严格模式后可明确结束本次休息；睡眠和锁屏算休息；技术选型可调整。

## 技术选择

采用 Swift Package Manager 管理纯 Swift 项目。SwiftUI 实现设置界面，AppKit 实现菜单栏和覆盖窗口，Core Image/Core Graphics 实现非生成式图片合成。最低支持 macOS 14，首先验证本机 Apple Silicon 环境。

不引入 Rust、Web 容器或第三方产品依赖。相较 Rust + Swift，纯 Swift 减少工具链和跨语言接口成本；相较 Web 容器，原生方案直接使用 macOS 的窗口与显示器能力。代价是未来跨平台可能需要迁移核心。

当前本机具备 Swift 6.3.2 和 Command Line Tools，没有 Rust 和完整 Xcode。使用 swift build/test 及脚本打包 .app；签名、公证、安装和权限提示的真实体验另做验证，不以命令行构建通过代替这些验证。

## 模块边界

- PauseGuardCore：纯 Foundation 的配置、状态机、计时策略、恢复决策及事件模型，不依赖界面或系统窗口。
- PauseGuardPlatform：单调时钟、活动检测、睡眠/锁屏事件、显示器管理、原子文件持久化及 Agent 通信。
- PauseGuardImages：素材导入、图集存储、缩略图、随机选择、五种模板合成及有界缓存。
- PauseGuardApp：菜单栏、首次配置、五栏设置界面、休息窗口及可读性效果。
- PauseGuardAgent：用户会话内的独立恢复进程，仅在应用异常消失且循环处于启用状态时尝试恢复。
- Scripts：构建、打包、显式安装/移除守护组件；测试不自动启用开机启动或覆盖真实桌面。

## 状态与计时

核心状态为 stopped、working、preparing、breaking、recovering、paused、error。每次转换记录原因及周期编号。preparing 是可选预告期，包含在工作时长内；背景合成始终异步，不阻塞进入休息。

固定模式累计电脑可用期间的经过时间；有效工作模式仅累计活动期间，闲置阈值默认为 60 秒。活动检测只使用系统空闲时长，不采集按键内容。两个模式在睡眠及锁屏期间均不累计工作时间。

使用包含睡眠经过时间的单调时钟计算休息，避免墙上时钟变化缩短休息。睡眠或锁屏发生在工作阶段时，累计这一段连续离开时间；若达到配置的休息时长，唤醒/解锁时开始完整的新工作周期；若不足，则恢复原工作剩余时间。睡眠和锁屏区间按并集处理，不重复计时。

休息阶段睡眠/锁屏时间计入当前休息。若到期时桌面仍不可用，则等待恢复桌面后开启下一工作周期，不消耗用户尚未返回时的工作时间。

持久化存储版本、状态、剩余时间、单调时间快照、系统启动标识及转换原因。同一次系统启动内恢复可计算实际经过时间；跨重启保留最后保存的剩余休息，不把关机时间视为休息。关键转换立即原子写入，运行期间定期保存检查点。

工作与休息时长修改于下一个对应周期生效；当前周期使用开始时的配置快照。严格模式切换下一次休息生效，避免当前界面和配置互相矛盾。

## 休息约束与恢复

每个显示器创建一个无普通关闭按钮的覆盖窗口，覆盖普通桌面应用并适配 Space 和全屏应用；显示器变化时重建对应窗口。支持程度通过实机矩阵记录，不宣称无法绕过系统界面。

严格模式不提供普通结束入口。非严格模式提供“结束本次休息”，点击后释放覆盖并开始下一工作周期。两种模式均可通过休息界面的“紧急解除”入口，进入独立确认步骤；确认后释放覆盖、记录事件并暂停循环。

不使用全局键盘屏蔽、内核扩展或更改系统安全设置。保留系统安全快捷键和辅助功能。工作期间允许退出；正常退出记录停止意图，Agent 不重新拉起。

渲染失败退回默认纯色背景；覆盖无法完整建立时释放已建窗口，暂停循环并显示可操作错误。计时故障时释放覆盖。主进程退出即由系统销毁其窗口，不让 Agent 持有永久遮挡能力。

Agent 使用受用户权限保护的本地状态及有限恢复协议。设置有限重启频率；连续失败停止自动恢复。通过打包与显式安装脚本管理 LaunchAgent，默认不在开发测试时改动登录项。

## 设置及素材

首次启动完成工作/休息时长、模式、严格模式和背景选择后明确启用循环。开机启动必须经用户主动确认。

设置按工作与休息、强制执行、休息背景、主题图集、通用设置分栏。时长范围沿用 PRD。支持提前休息、暂停和恢复；休息期间禁止用设置入口绕过严格模式。

图片复制到 Application Support 内部素材库，以稳定 ID 引用；支持 PNG、JPEG、HEIC，导入时验证文件并生成缩略图。删除素材同步更新图集及缓存引用。默认图集可直接使用，另支持创建、命名、启停和删除自定义图集。

实现 Hero、Grid、Collage、Cinematic、Minimal 模板，支持单图、拼贴及随机模板。选择时避免连续重复相同组合与模板；素材不足时减少图片数，无素材或失败时回退默认背景。

每个屏幕按实际尺寸渲染，限制离屏图像与缓存大小，图片解码先降采样。后台提前合成；休息触发时使用就绪缓存或默认背景，不等待图片任务。倒计时与随机文案使用固定安全区域、对比遮罩和大字号。

所有数据保存在本机，不上传图片、不要求账号。支持减少动画、减少透明度、键盘导航及 VoiceOver 标签。

## 数据与故障处理

使用 Codable JSON 存储设置、图集、素材元数据与运行状态，各自带 schemaVersion。通过临时文件替换进行原子写入。损坏文件保留以便诊断，加载安全默认值；运行状态无法可信恢复时暂停，避免错误锁屏。

事件日志仅记录状态、错误、紧急解除及恢复原因，设定大小上限，不记录私人应用内容。图片损坏、丢失、色彩空间及方向异常应按单张素材隔离处理。

## 验证与完成标准

核心用可注入时钟验证：完整循环、预告、有效工作、时钟变化、睡眠/锁屏并集、提前结束、紧急解除、同启动恢复及跨重启恢复。

存储验证原子往返、损坏降级及配置边界；图片验证格式导入、五模板、空库、损坏文件及缓存限制；恢复组件验证显式退出不重启、异常重启限速。

构建应用及 Agent，运行 Swift 测试，验证 .app 布局与可执行文件，提供构建说明及人工验收清单。使用缩短周期的显式开发模式验证界面，避免修改正常生产配置。

人工矩阵覆盖多显示器、Retina、热插拔、主屏切换、全屏 Space、Mission Control、睡眠/锁屏、VoiceOver、后台编译、UI 崩溃和紧急解除。未执行的场景标记为待验证，不能当作通过。

完成意味着 PRD 的完整功能已实现且可本地构建运行，自动化验证通过，实机验证结果及已知平台限制已记录。公开分发所需的开发者签名、公证与跨平台支持不计入本次本地 MVP 交付。
