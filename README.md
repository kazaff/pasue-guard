# PauseGuard

macOS 菜单栏休息应用：工作计时到期后显示休息覆盖、倒计时和本地图片背景；休息结束后进入下一工作周期。支持固定时间与有效工作时间、严格/非严格休息、图集和紧急解除。

当前为本地 MVP 候选版本。自动测试及应用包校验已执行；真实桌面交互验收仍待完成，详见 [验收清单](docs/acceptance.md) 和 [验证记录](docs/verification.md)。

## 构建与运行

需要 macOS、Swift 6.3.2 工具链（本机使用 Command Line Tools）。包声明最低 macOS 14；实际构建测试环境为 macOS 26.5.2、Apple Silicon。当前输出为 arm64、ad hoc 本地签名，未提供 Developer ID 签名或公证。

在仓库根目录运行：

```sh
bash Scripts/test.sh
bash Scripts/build-app.sh
bash Scripts/check-app.sh
open dist/PauseGuard.app
```

也可使用本机绝对路径：

```sh
bash ./Scripts/build-app.sh
open ./dist/PauseGuard.app
```

构建脚本执行 release 构建，打包主程序、独立 Agent 和两个 LaunchAgent plist，并校验本地签名。测试脚本为 CLT 的 Swift Testing 配置框架路径；无需完整 Xcode。测试不安装登录项、不启动真实覆盖窗口、不改变睡眠或锁屏状态。

首次打开后，从菜单栏进入配置：设置工作时长（5～180 分钟）、休息时长（1～60 分钟）、计时模式、严格模式和背景，然后明确启用循环。默认 45 分钟工作、5 分钟休息。开机启动初始关闭，需主动启用。工作时可提前休息、暂停/继续或退出。当前工作时长、当前休息时长和严格程度使用各阶段快照；修改分别从下一个工作/休息阶段生效。

开发演示使用独立临时数据和加速时钟（约 20 秒工作、4 秒休息），仍会显示真实覆盖，应在可中断的桌面操作中运行：

```sh
open -n dist/PauseGuard.app --args --demo
```

## 背景与本地数据

在“休息背景”批量导入 PNG、JPEG、HEIC，选择单图或拼贴；在“主题图集”管理名称、启用状态和素材集合。支持 Hero、Grid、Collage、Cinematic、Minimal 和随机模板。HEIC 真实文件解码尚待验证。图片复制到内部库，源文件可保留在原位置；合成失败使用默认背景，不等待合成才进入休息。

图集编辑器的“预览全部模板”使用当前未保存的图片选择，同时显示五种具体布局；点击卡片只更改草稿，点击编辑器“保存”后才生效。“随机模板”仍会在每次休息时挑选具体布局。预览遵循单图与减少视觉刺激偏好，以主显示器的逻辑点尺寸保持面板和照片比例（无显示器时 16:9），并以低分辨率异步生成，不改变当前计时或下次休息背景。

休息画面保留照片主体的亮度与颜色，倒计时和文案集中在局部磨砂玻璃面板中。面板使用与屏幕照片一致的裁切与位置进行局部模糊，让背景颜色和大轮廓透出；macOS 26 叠加原生 Clear Liquid Glass 边缘，macOS 14/15 使用同一照片模糊层及细描边。倒计时优先使用系统已有的 DIN Condensed，中文文案优先使用宋体，缺失时使用系统字体；文字与内联紧急解除控件带局部深色细阴影，在明亮照片上保留字形轮廓；减少透明度时仅面板改为实色。真实桌面上的材质、辅助功能与多屏效果仍待人工验收。

数据目录为 `~/Library/Application Support/PauseGuard/`：`settings.json` 保存计时配置，`preferences.json` 保存界面偏好，`session.json` 保存运行快照，`Images/` 保存素材、缩略图与 `library.json`，`events.log` 保存有界事件日志，`agent-history.json` 保存独立的恢复次数与耗尽记录。损坏状态不会直接恢复覆盖；配置/状态在显式替换保存时保留 `.preserved-*` 诊断副本。图片库元数据损坏或版本过新时先使用空库；下一次明确导入有效图片或保存主题时，把原 `library.json` 移到唯一的 `library.json.preserved-*`，再保存新库，保留旧原图和缩略图。实际磁盘读写失败仍报错，不当作空库恢复。数据和图片仅在本机使用，不需账号。

## 开机启动与 Agent

设置中的开机启动开关会安装或移除当前用户的两个任务：`com.pauseguard.login` 在登录时打开应用，`com.pauseguard.agent` 检查异常消失并有限恢复。正常退出保存停止意图，当前会话中不会由守护程序重新拉起。系统注销/重启则保留未完成快照和恢复意图，下一次打开时继续（真实系统事件投递仍待验收）。Agent 每次明确启用后最多自动尝试三次；预算耗尽后持续停止，即使超过五分钟或 Agent 重启也不恢复次数，短暂出现进程亦不重置。只有成功重新启用开机启动（关闭再打开，或移除后重新安装）才重置预算；单独手动打开应用不会重置。旧版、损坏或未知版本的恢复记录也先停止，明确重新启用时保留诊断副本再重置。它不拥有覆盖窗口。

需要手动管理时，在已登录用户下执行（无需 sudo；先构建并保持应用路径稳定）：

```sh
bash Scripts/install-agent.sh ./dist/PauseGuard.app
bash Scripts/uninstall-agent.sh ./dist/PauseGuard.app
```

脚本会实际修改 `~/Library/LaunchAgents/com.pauseguard.agent.plist` 和 `~/Library/LaunchAgents/com.pauseguard.login.plist` 并调用用户会话 launchctl。此轮验证没有执行安装/移除或登录重启实验。应用移位或删除前先关闭开机启动/移除两个任务；若设置显示清理失败，按所示路径处理并重试清理。

## 紧急恢复

休息界面选择“紧急解除…”并确认后，所有覆盖释放，循环保存为暂停；恢复循环需要明确继续。非严格模式也可选择“结束本次休息”，立即开始下一工作周期。严格休息期间普通暂停、退出和提前结束不可用。

若界面失去响应，使用 macOS 的强制退出结束 PauseGuard，主进程结束即释放其窗口；系统安全快捷键不被拦截。若已启用 Agent，异常退出可能触发有限重新打开；移除上述登录任务后再正常退出可停止守护。需重置时，先停用 Agent 并退出应用，再备份整个数据目录，将 `session.json` 移到目录之外后重开，可清除当前循环快照而保留设置和图片。

覆盖对 Space、Mission Control、全屏应用和辅助功能的实际效果依赖 macOS。当前不能承诺无法绕过，也尚未完成真实紧急解除、VoiceOver、多屏及登录恢复验收。

## 图标、提前预告与视频背景

- 应用图标为原创深蓝底、薄荷绿暂停符号和呼吸光环。`Resources/PauseGuard.icns` 随包分发；在 macOS 上可用 `swift Scripts/generate-icon.swift` 重新生成，预览为 `Resources/PauseGuard-icon.png`。
- 设置中将“提前预告”设为大于 0 秒后，主屏右上角显示预告倒计时。预告内可跳过，随后重新开始完整工作周期；下一次休息按 2、4、8 倍递增，最多 60 分钟。完成完整休息（含足够长的睡眠或锁屏休息）后恢复正常；普通提前结束仍保留累计状态。累计状态保存在会话中，正常退出、重启不会清除。
- 严格模式紧急解除需先等待 5 秒，再输入当前显示的 4 位数字并确认。返回休息随时可用，重新进入重新等待和验证。解除后释放所有屏幕并暂停；非严格模式仍可直接结束本次休息。
- 屏保约 0.8 秒淡入，正常结束约 0.6 秒模糊淡出。淡出画面只作装饰，输入限制立即释放；锁屏、睡眠、退出和错误清理立即撤除。开启系统“减少动态效果”后取消动画。
- 背景设置可导入单个本地 MP4，验证后复制到应用资料目录，替换时保留旧设置直至新文件及配置保存成功。休息时所有屏幕播放同一个文件，各自静音循环；播放失败回退图片。开启“减少视觉刺激”时停止视频并使用无照片的深色背景。模板图库预览仍用于静态图片布局。
